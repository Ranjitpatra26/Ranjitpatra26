## Featured Projects

<details>
<summary><strong>MOOD-WAVE — Emotion + Weather AI Music Engine</strong></summary>

<br/>

> An intelligent music recommendation and playback system that fuses **real-time facial emotion recognition** with **live weather data** to autonomously select and play music matched to the user's current psychological and environmental state.

<div align="center">

| Attribute | Details |
|:---|:---|
| **Stack** | HTML5 · CSS3 · JavaScript · Spotify Web API · YouTube Data API v3 · Face Detection API · OpenWeatherMap API |
| **Scale** | Client-side single-page application with multi-API orchestration |
| **Performance** | Real-time emotion inference at browser frame-rate; sub-2s weather + music resolution |
| **AI Layer** | Facial landmark detection → emotion classification → multi-signal recommendation engine |
| **Integration** | Dual music service support: Spotify playback + YouTube embed fallback |
| **Impact** | Demonstrates full AI pipeline integration without server infrastructure |
| **Repository** | [github.com/Ranjitpatra26/MOOD-WAVE](https://github.com/Ranjitpatra26/MOOD-WAVE) |

</div>

The system captures webcam frames, runs emotion inference locally in the browser, simultaneously fetches geolocation-based weather data, and composes both signals into a recommendation query dispatched to the Spotify and YouTube APIs. The result is a zero-latency, fully personalized music experience that responds to who you are and where you are in real time.

</details>
